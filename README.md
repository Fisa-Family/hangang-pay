# Hangang-Pay

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/09b5e227-f1c1-4efb-a4db-7ddb8c0b682b" />

블록체인 기반 차세대 지역화폐 플랫폼, 한강페이

한강페이는 블록체인 기반 CBDC 인프라를 구축하여, 소비자의 결제 즉시 가맹점에 정산이 이루어지는 동적 정산 시스템을 도입했습니다. 이를 통해 소상공인은 기존 카드사의 수수료 부담에서 벗어나 수수료 0원의 즉시 정산을 직접 경험할 수 있습니다. 동일한 인프라를 바탕으로 지역화폐를 넘어 다양한 정책자금 운용으로 확장 가능한 새로운 금융 인프라를 제시합니다.
