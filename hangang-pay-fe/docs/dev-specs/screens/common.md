# 공통 화면 명세

대상 화면: C-\*

---

## 공통 하단 내비게이션

### C-NAV-USER 사용자 하단 내비게이션

- 타입: component (하단 고정)
- 사용 화면: U-01, U-MY-01, U-MY-PAY-01 등 user 권한 화면

**탭 구성**
| 탭 | 스타일 | 이동 |
|----|--------|------|
| 홈 | 기본 | /home |
| 결제내역 | 기본 | /mypage/payments |
| QR 스캔 | 강조색, 중앙 | /pay/scan |
| 가맹점 | 기본 | 미구현 |
| 마이페이지 | 기본 | /mypage |

---

### C-NAV-MERCHANT 가맹점 하단 내비게이션

- 타입: component (하단 고정)
- 사용 화면: M-01, M-PAY-01, M-MY-01 등 merchant 권한 화면

**탭 구성**
| 탭 | 이동 |
|----|------|
| 홈 | /merchant/home |
| 내역 | /merchant/payments |
| 마이 | /merchant/mypage |

---

### C-LOGOUT-01 로그아웃 확인

- 타입: modal (route 없음, 부모 화면 위 오버레이)
- 진입: U-MY-01, M-MY-01에서 로그아웃 탭 시

**UI**

- 확인 메시지: 로그아웃하시겠습니까?
- 버튼: 취소, 로그아웃

**액션**
| 트리거 | 이동 |
|--------|------|
| 로그아웃 | /login (모달 닫고 이동) |
| 취소 | 모달 닫기 (부모 화면 유지) |

---

### C-ERROR-01 네트워크 오류

- 타입: page (fullscreen)
- 경로: /error

**UI**

- 오류 아이콘
- 제목: 연결에 실패했습니다
- 메시지: 네트워크 상태를 확인하고 다시 시도해주세요
- 버튼: 다시 시도, 홈으로

**액션**
| 트리거 | 이동 |
|--------|------|
| 다시 시도 | router.back() 또는 retry callback (이전 요청 화면) |
| 홈으로 | /home 또는 /merchant/home (사용자 타입에 따라) |

---

### C-SESSION-01 세션 만료 안내

- 타입: page (fullscreen)
- 경로: /session-expired

**UI**

- 자물쇠 또는 시계 아이콘
- 제목: 세션이 만료되었습니다
- 메시지: 보안을 위해 자동으로 로그아웃되었습니다. 다시 로그인해주세요
- 버튼: 로그인하기

**액션**
| 트리거 | 이동 |
|--------|------|
| 로그인하기 | /login |

---

### C-PERM-01 카메라 권한 안내

- 타입: modal 또는 page
- 진입: U-PAY-01 QR 스캔 화면에서 카메라 권한 거부 시

**UI**

- 카메라 아이콘
- 제목: 카메라 권한이 필요합니다
- 메시지: QR 결제를 위해 카메라 접근 권한을 허용해주세요
- 버튼: 권한 설정, 닫기

**액션**
| 트리거 | 이동 |
|--------|------|
| 권한 설정 | 브라우저 권한 안내 표시 및 카메라 재시도 |
| 닫기 | /home |
