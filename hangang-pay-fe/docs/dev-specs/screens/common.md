# 공통 화면 명세

대상 화면: C-\*

---

## 공통 하단 내비게이션

### C-NAV-USER 사용자 하단 내비게이션

- 타입: component (하단 고정)
- 사용 화면: U-01, U-MY-01, U-MY-HIST-01 등 user 권한 화면

**탭 구성**
| 탭 | 스타일 | 이동 |
|----|--------|------|
| 홈 | 기본 | /home |
| 내역 | 기본 | /mypage/history |
| QR 결제 | 강조색, 중앙 | 카메라 QR 처리 시작 |
| 가맹점 | 기본 | 미구현 |
| 마이페이지 | 기본 | /mypage |

---

### C-NAV-MERCHANT 가맹점 하단 내비게이션

- 타입: component (하단 고정)
- 사용 화면: M-01, M-PAY-01, M-MY-01 등 merchant 권한 화면

**탭 구성**
| 탭 | 이동 |
|----|------|
| 홈 | /merchant/home |
| 내역 | /merchant/payments |
| 마이 | /merchant/mypage |

---

### C-LOGOUT-01 로그아웃 확인

- 타입: modal (route 없음, 부모 화면 위 오버레이)
- 진입: U-MY-01, M-MY-01에서 로그아웃 탭 시

**UI**

- 확인 메시지: 로그아웃하시겠습니까?
- 버튼: 취소, 로그아웃

**액션**
| 트리거 | 이동 |
|--------|------|
| 로그아웃 | /login (모달 닫고 이동) |
| 취소 | 모달 닫기 (부모 화면 유지) |
